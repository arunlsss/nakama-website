What your dashboard can measure

Import coverage and freshness

Metric definitions

All order value
Price × Quantity across every included order status. Canceled and returned orders are included.
Active order value
Completed, To Ship, Shipped and Unpaid order value. Canceled, Return & Refund and unclassified statuses are excluded. This is not recognized revenue.
Completed order value
Price × Quantity for Completed items only. Canceled items in partially canceled orders are excluded. No fees, costs or actual payout adjustments are applied.
Cancellation / return rate
Fully canceled orders, or returned orders, ÷ all included orders for the same dates, store and marketplace. Partially canceled orders count once as completed, while canceled item value remains in All order value. This follows order placement dates, not cancellation or return event dates.
Average order value
Selected order value ÷ selected orders.
Product order counts
Orders containing each SKU. One order may contain multiple SKUs, so these counts must not be added to obtain total orders.
Advertising return and profit
Shopee advertising return is available in Advertising after importing ad reports. Contribution profit still requires settlement and cost records. Missing data is not treated as zero.

Import history

Recent confirmed uploads across your workspace

Order value is not payout or profit. Figures reflect imported snapshots, not live marketplace data.
